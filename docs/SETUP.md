# 뷰티포스트 — 기능 요약과 운영 설정 순서

## 1. 지금 되는 기능

### 원장님이 쓰는 기능 ("만들기")

| 단계 | 하는 일 |
|---|---|
| ① 무엇을 만들까요 | 업종 9개(반영구 눈썹·속눈썹·네일·헤어·두피문신·입술 반영구·왁싱·피부관리·메이크업)와 목적 6개(비포·애프터·시술 과정·원장님·샵 소개·고객 후기·이벤트·예약 안내·관리 팁) 고르기 |
| ② 사진·영상 올리기 | "비포", "애프터", "시술 과정"처럼 칸별로 올림. 사진에 고객 얼굴이 보이면 "게시 동의 받았어요 / 빼기"를 묻고(여러 장이면 한 번에), 영상은 항상 "고객 얼굴이 나오나요?"를 물음. 얼굴 가림은 브랜드 설정에서 켠 경우만 |
| ③ 스타일 고르기 | 무드 5개(깔끔·화이트톤, 웜·내추럴, 모던·블랙&골드, 러블리·파스텔, 트렌디·빠른 컷)를 **내 사진에 입힌 미리보기**로 고름. 만들 것(글·사진·영상)과 사진 크기·영상 형식 선택, **시술 메모**(기법·색·고객 요청 — 글이 구체적이 됨) |
| ④ 결과 | 아래 표 |

| 결과물 | 내용 | 원장님이 할 일 |
|---|---|---|
| 게시글 초안 | 인스타 후보 3개 — 형식이 서로 다름(시술 기록 / 한 장면 대화 / 짧은 팁), 글 끝 **고정 안내 문구** + 해시태그(기본 5개, 지역+시술 먼저). 네이버 블로그 후보 2개(탭을 열 때 생성), 카카오톡 문구. 보통 5~10초 | **복사** 버튼 → 붙여넣기 |
| 보정 사진 | 자동 밝기·색 교정 + 무드 색감, 피드 4:5·1:1·스토리 9:16, 비포·애프터 한 장(같은 보정값, 세리프 "Before / After" 이름표), 샵 이름·로고 넣기. 보통 5초 안팎 | **저장** (휴대폰은 공유 창 → 사진 앱) |
| 영상 | 릴스·스토리·피드용 8~14초. 결과 한마디 → 비포 → 과정 → 애프터(시술 부위 클로즈업) → 위아래 비교 + 샵 이름 띠, 세리프 이름표·반투명 자막 띠·워터마크. 맥 작업자가 켜져 있으면 30초 안팎 | 완성 알림 → **저장** → 인스타 앱에서 음악 추가 (소리 없이 만듦, 추천 장르 안내) |

- 과장·의료 표현("부작용 없음", "100%", "평생 유지" 등)은 자동으로 찾아 고치고, 남은 건 화면에 표시
- 보정은 밝기·색감까지만 (시술 부위 모양을 바꾸는 기능은 없음)
- 고른 글·고친 글은 다음 생성 때 원장님 말투로 반영

### 그 밖의 화면
- **브랜드 설정** (더보기 → 브랜드 설정): 기본 업종·분위기, 브랜드 컬러, 로고, 예약 안내 한 줄, **글 끝 고정 안내 문구**, 해시태그 개수·고정 해시태그, 인스타 아이디(영상 워터마크), 얼굴 가림 사용(기본 끔), 내 말투 샘플
- **만든 영상** (더보기, 홈의 빠른 시작): 진행 중인 영상의 진행률과 완성된 영상 저장
- 기존 기능(캘린더, 게시물 목록, 고객 관리, 알림)은 그대로. 인스타그램 계정 연동·자동 게시는 꺼 둠(`FEATURE_INSTAGRAM=true` 로 다시 켤 수 있음)

### 운영자가 하는 일
- 새 분위기·업종·목적은 `presets/` 에 파일 추가로 (README "스타일 프리셋 추가하기")
- 영상은 **맥에서 켜 둔 렌더 작업자**가 만든다. 맥이 꺼져 있으면 영상은 "순서를 기다리는 중"으로 남았다가 맥이 켜지면 이어서 만들어짐 (글·사진은 맥과 상관없이 바로)

## 2. 설정 순서 (처음 한 번, 약 30분)

현재 상태 확인 결과 (2026-10-24):
- ✅ Gemini AI 키(`GOOGLE_GENERATIVE_AI_API_KEY`)는 Vercel 에 이미 있음
- ⚠️ 연결된 Blob 저장소 `beautypost-media` 가 **비공개(Private)** 이고 업로드 토큰(`BLOB_READ_WRITE_TOKEN`)이 없음
  → 이 상태로는 사진 업로드가 저장되지 않음 (저장소 파일 0개). 이 앱은 공개 저장소가 필요하고, 저장소의 공개/비공개는 만든 뒤 바꿀 수 없음
- ⚠️ 마지막 운영 배포가 16일 전 → 이번 작업은 아직 배포 안 됨

### 1단계. 공개 Blob 저장소 만들기 (5분, Vercel 대시보드)

1. https://vercel.com → 프로젝트 **beautypost** → 위 메뉴 **Storage**
2. **Create** → **Blob** 선택
3. 이름: `beautypost-public`, 접근 방식: **Public**, 지역: 목록에 **Seoul(icn1)** 이 있으면 그것(원장님 휴대폰과 가까워 빠름), 없으면 기존과 같은 **Washington, D.C.(iad1)** → 만들기
4. 만든 저장소 화면 → **Projects** 탭 → **Connect to Project** → `beautypost`, 환경 **Production** (+ Preview) 선택
   - 이미 `BLOB_STORE_ID` 가 있다며 접두어(prefix)를 물으면 아무 이름(예: `PUBLIC`)을 넣어도 됨 (이 앱은 그 값을 쓰지 않음)
5. 저장소 화면에서 **`BLOB_READ_WRITE_TOKEN`** 값을 찾아 복사 (보통 저장소 화면의 `.env.local` 탭 또는 설정의 토큰 항목에 `vercel_blob_rw_…` 로 시작하는 값으로 보임)

> 기존 비공개 저장소(`beautypost-media`)는 비어 있으니 그대로 둬도 되고 지워도 됩니다.

### 2단계. Vercel 환경변수 추가 (5분)

프로젝트 **beautypost** → **Settings** → **Environment Variables** → **Add** (환경: **Production**, 필요하면 Preview 도)

| 이름 | 값 | 설명 |
|---|---|---|
| `BLOB_READ_WRITE_TOKEN` | 1단계에서 복사한 `vercel_blob_rw_…` | 사진·영상 업로드 (필수) |
| `RENDER_WORKER_TOKEN` | 아래 명령으로 만든 긴 무작위 문자열 | 맥 작업자 ↔ 서버 비밀번호 (필수) |

`RENDER_WORKER_TOKEN` 만들기 (맥 터미널):
```sh
openssl rand -hex 32
```
→ 나온 값을 **메모해 두기** (5단계에서 맥에도 똑같이 넣음)

> `FEATURE_INSTAGRAM` 은 넣지 않으면 꺼짐 (지금 원하시는 상태). AI 키는 이미 있음.

### 3단계. 운영 DB 업데이트 (5분, 맥 터미널)

새 기능용 표·칸을 운영 DB 에 추가합니다 (추가만 하고 기존 데이터는 바꾸지 않음).

1. `.env.local` 의 `DATABASE_URL` 이 Vercel 의 운영 DB 와 같은지 확인
   (Vercel → Settings → Environment Variables → `DATABASE_URL` 값 보기와 비교. 다르면 `.env.local` 값을 운영 값으로)
2. (권장) Neon 콘솔에서 백업 브랜치 하나 만들기: https://console.neon.tech → 프로젝트 → **Branches** → **Create branch**
3. 실행:
   ```sh
   cd ~/beautypost
   pnpm --filter @beautypost/api db:migrate
   ```
   오류 없이 끝나면 완료 (0003·0004 적용)

### 4단계. 코드 합치고 배포 (10분)

```sh
cd ~/beautypost
git checkout main
git merge feat/stage1-presets
git push origin main
vercel --prod
```
- GitHub 연동으로 자동 배포가 켜져 있다면 `git push` 만으로 배포되고 `vercel --prod` 는 생략
- 배포 확인: 브라우저에서 `https://<서비스 주소>/api/presets` → 분위기 5개 목록(JSON)이 보이면 정상

### 5단계. 맥에 영상 작업자 켜기 (5분, 맥 터미널)

영상 엔진은 `pnpm install` 이 받아 두는 ffmpeg 만 있으면 됩니다 (filmcraft 는 필요 없음).

```sh
cd ~/beautypost
pnpm install && pnpm build        # 최신 코드 준비 (4단계 후 한 번)
cd apps/worker
RENDER_API_URL=https://<서비스 주소> RENDER_WORKER_TOKEN=<2단계 값> ./scripts/install-launchd.sh
```
- 이제 맥에 로그인하면 작업자가 자동으로 켜지고, 꺼지면 다시 켜집니다
- 잘 도는지 보기: `tail -f ~/Library/Logs/beautypost-worker.log` → `작업자 … 시작` 이 보이면 정상
- 끄기: `./scripts/install-launchd.sh --uninstall`
- **맥이 잠자기에 들어가지 않게**: 시스템 설정 → 에너지(또는 배터리) → "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" 켜기
- 코드를 새로 받은 뒤에는 `pnpm install && pnpm build` 후 작업자를 다시 켭니다: `launchctl kickstart -k gui/$(id -u)/com.beautypost.worker`

### 6단계. 휴대폰으로 확인 (10분)

1. 휴대폰으로 서비스 접속 → 로그인
2. **더보기 → 브랜드 설정**: 업종·기본 분위기·예약 안내 문구 넣고 저장, 직접 쓴 인스타 글 2~3개를 "내 말투 샘플"로 추가
3. **만들기**: 비포·애프터 사진 1장씩 + (선택) 시술 영상 → 분위기 고르기 → 글·사진·영상 모두 체크 → 만들기
4. 확인할 것
   - 글: 후보가 나오고 **복사**가 되는지, 네이버 블로그에 `[사진 1]` 자리가 있는지
   - 사진: **저장** → 사진 앱에 들어가는지
   - 영상: 진행률이 움직이고 30초 안팎에 완성 → **영상 저장**
5. 문제가 있으면: 맥 작업자 로그(`~/Library/Logs/beautypost-worker.log`)와 Vercel → **Logs** 를 함께 보내 주세요

## 3. 알아 두면 좋은 것

- **아이폰 사진(HEIC)**: 사파리에서는 자동으로 JPG 로 바꿔 올림. 안 되면 "아이폰 설정 → 카메라 → 포맷 → 높은 호환성" 안내가 뜸
- **영상 BGM**: 일부러 넣지 않음 → 인스타 앱에서 음악 추가 (결과 화면에 무드별 추천 장르 표시)
- **결과 파일 주소**: 추측할 수 없는 공개 주소. 고객 원본 사진의 비공개 저장은 다음 개선 항목
- **AI 비용·속도**: Gemini 를 "생각 최소"(`AI_THINKING=minimal`)로 써서 글 한 번에 수 초. 호출마다 걸린 시간이 Vercel 로그에 `[AI] 작업 모델 n.n초` 로 남음. Gemini 가 실패하면 Vercel AI Gateway(Claude)로 넘어가는데, **Gateway 는 Vercel 팀에 결제 카드를 등록해야 동작함** (지금은 미등록이라 대체가 안 됨). 하루 생성 한도 20회/사용자
- 개발 중 로컬 실행·테스트 방법은 README.md, 구조는 docs/ARCHITECTURE.md
